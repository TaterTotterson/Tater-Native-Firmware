- Release native firmware **0.7.0** for Voice PE, Satellite1, ReSpeaker XVF3800, and ESP32-S3-BOX-3, retaining the 0.6.8 wake-boundary and SAT1 microphone gain corrections.
- **USB Ethernet and PoE in all four images:** SAT1, Voice PE, ReSpeaker XVF3800, and ESP32-S3-BOX-3 enable the shared USB Ethernet implementation in release build `native-0.7.0-rev1`. SAT1 and Voice PE passed Ethernet voice requests, downloaded speech playback, cold starts, and both USB-C orientations. ReSpeaker and S3 Box hardware operation with the adapter remains untested.
- **Tested adapter:** [UCTRONICS B0B9ZLVGJ4 (U6113)](https://www.amazon.com/dp/B0B9ZLVGJ4), the same powered adapter used with Tater Echo Firmware, plus a **data-capable Micro-USB female → USB-C male converter**. Connect it to the board's ESP32 USB port and cold boot through the adapter.
- Other powered RTL8152 adapters exposing USB **0bda:8152 / CDC-ECM configuration 2** may work but are untested. Other chipsets and power-only splitters are not supported; a USB-C plug or higher wattage alone does not establish compatibility. This adapter supplies 5 V and does not enable SAT1's higher-voltage amplifier modes.
- Prefer Ethernet after DHCP while retaining saved Wi-Fi as fallback. Reconnect Tater and Sendspin when the selected interface or address changes; playback may pause during a handoff. Preserve USB serial when booting directly on a computer, and retain settings and existing XMOS firmware during app-only updates.
- Fix aligned USB Ethernet frame boundaries, mDNS hostname self-conflicts, and same-subnet routing so actual Tater traffic uses Ethernet. Add network status diagnostics and host regressions for routing, startup cleanup, adapter filtering, and recovery.
- Update to **Tater 3.0.8** for live USB Ethernet labels and wake readiness in satellite diagnostics. See the [USB Ethernet guide](https://github.com/TaterTotterson/Tater-Native-Firmware/blob/native-0.7.0-rev1/docs/usb-ethernet.md) for setup and recovery. Extended music/power soak and live failover with power retained remain unverified on hardware.
